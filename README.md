# Proyecto Monitor
## Descripción
Este proyecto es una aplicación que permite monitorear en tiempo real el uso de los recursos principales de un sistema: CPU, memoria, disco y red. Ejecuta una ventana con un informe.

1. **Métodos**
 Comando psutil para realizar un analisis.<br>
 Comando git para crear versiones en diferentes ramas.<br>
 Comando tkinter para genarar una ventana emergente.<br>
 Funcion while genera un bucle de repetición.<br>

## Instalación
Ejecutamos el programa y este realiza un analisis detallado, genera un informe en una ventana emergente

## Uso
Muestra de manera clara y concisa la utilización de cada recurso, permitiendo identificar posibles cuellos de botella y optimizar el rendimiento del sistema.
