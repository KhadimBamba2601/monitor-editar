# Evaluación final practica
Proyecto de Monitor
## Descripción
Este proyecto es una aplicación que permite monitorear en tiempo real el uso de los recursos principales de un sistema: CPU, memoria, disco y red.
Muestra de manera clara y concisa la utilización de cada recurso, permitiendo identificar posibles cuellos de botella y optimizar el rendimiento del sistema.
